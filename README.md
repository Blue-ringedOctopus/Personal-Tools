# Personal-Tools
存放个人在文献研究、数据分析时制作使用的小工具，基本没有参考/复现价值，仅作存档。

项目一：split_to_excel
情景：校勘《金匮要略》吴迁本、邓珍本、赵开美本过程中，将整理好异文的txt文档转换为一定格式的excel文档。
需求txt内容格式示例：
43.（茵蔯蒿湯）吴迁本：梔子[拾]肆枚擘
邓珍本：梔子[十]四枚（对比吴迁本，共3处）
赵开美本：梔子[十]四枚（对比吴迁本，共3处）
excel内容示例：
A   序号: 43
B   吴迁本: 梔子[拾]肆枚擘
C   邓珍本: 梔子[十]四枚
D   赵开美本: 梔子[十]四枚
E   校勘对象: 
F   致误原因: 
G   判断依据: 
H   备注: 茵蔯蒿湯
I   邓本附注: 对比吴迁本，共3处
J   赵本附注: 对比吴迁本，共3处
拓展：修改代码中关键词后，可整理按以上格式的任意复数版本的对比文档。

项目二：folder_to_excel_patients
情景：
原始数据按照特定的文件夹结构存放：根目录/日期+门诊+医生/患者姓名/
需要将每一名患者的姓名及其对应的就诊日期提取出来，汇总为一份 Excel 表格，以便后续统计分析或归档。
输入需求：
一个根目录路径。
该目录下第一层为「日期文件夹」，命名格式为 年份年月份月日期[日号] 其他信息（如 2025年11月13日 xx门诊 成员姓名）。
第二层为「患者文件夹」，命名即为患者姓名（如 张三）。
输出：
一个新的 Excel 文件（.xlsx），包含以下列：
B 列：患者姓名（从第二层文件夹名获取）
C 列：就诊日期（从第一层文件夹名解析，格式为 YYYY/M/D，如 2025/11/13）
表格包含表头（姓名、日期），数据从第 2 行开始写入。
约束：
仅遍历深度为 2 的文件夹（根目录记为深度 0），不递归深入更深层级。
日期解析支持“日”和“号”两种结尾（2025年11月13日 或 2025年11月13号）。
忽略日期文件夹名中日期之后的所有文字（如门诊、医生等信息），仅提取年月日数字。
