# Personal-Tools
存放个人在文献研究、数据分析时制作使用的小工具，基本没有参考/复现价值，仅作存档。

项目一：split_to_excel
情景：校勘《金匮要略》吴迁本、邓珍本、赵开美本过程中，将整理好异文的txt文档转换为一定格式的excel文档。
需求txt内容格式示例：
43.（茵蔯蒿湯）吴迁本：梔子[拾]肆枚擘
邓珍本：梔子[十]四枚（对比吴迁本，共3处）
赵开美本：梔子[十]四枚（对比吴迁本，共3处）
excel内容示例：
A   序号: 43
B   吴迁本: 梔子[拾]肆枚擘
C   邓珍本: 梔子[十]四枚
D   赵开美本: 梔子[十]四枚
E   校勘对象: 
F   致误原因: 
G   判断依据: 
H   备注: 茵蔯蒿湯
I   邓本附注: 对比吴迁本，共3处
J   赵本附注: 对比吴迁本，共3处
拓展：修改代码中关键词后，可整理按以上格式的任意复数版本的对比文档。

项目二：folder_to_excel_patients
情景：
原始数据按照特定的文件夹结构存放：根目录/日期+门诊+医生/患者姓名/
需要将每一名患者的姓名及其对应的就诊日期提取出来，汇总为一份 Excel 表格，以便后续统计分析或归档。
输入需求：
一个根目录路径。
该目录下第一层为「日期文件夹」，命名格式为 年份年月份月日期[日号] 其他信息（如 2025年11月13日 xx门诊 成员姓名）。
第二层为「患者文件夹」，命名即为患者姓名（如 张三）。
输出：
一个新的 Excel 文件（.xlsx），包含以下列：
B 列：患者姓名（从第二层文件夹名获取）
C 列：就诊日期（从第一层文件夹名解析，格式为 YYYY/M/D，如 2025/11/13）
表格包含表头（姓名、日期），数据从第 2 行开始写入。
约束：
仅遍历深度为 2 的文件夹（根目录记为深度 0），不递归深入更深层级。
日期解析支持“日”和“号”两种结尾（2025年11月13日 或 2025年11月13号）。
忽略日期文件夹名中日期之后的所有文字（如门诊、医生等信息），仅提取年月日数字。

├── create_excel_with_data(excel_path, data)   # 新建 Excel 并写入数据
└── main()                                     # 主流程，设置路径并执行

项目三：get_folder_from_excel.py
情景：对特定患者（如 IBS-C 组）的多次就诊数据进行前后对照分析。原始病历按“日期/门诊/医生/患者/就诊日期”的层级存放，而我们需要根据 Excel 中记录的患者就诊日期，提取其前一次和后一次就诊的完整病历文件夹，以便进行纵向对比研究。

输入需求：
源根目录（source_root）
存放所有原始病历的顶层目录，结构为：日期文件夹/.../Aurum.../患者姓名/YYYY-MM-DD/
Excel 文件（excel_path）：包含 B 列（姓名） 和 C 列（日期），日期格式可为 2025/2/10、2025-02-10 等。
目标根目录（target_root）：复制目标，脚本会将选中的相邻日期文件夹复制到 目标根目录/患者姓名/YYYY-MM-DD/ 下。

输出：
在目标根目录下生成按患者分组的相邻日期文件夹（仅复制基准日期前后的最近各一次，若存在）。
控制台输出详细的处理日志及最终统计报告（总患者数、找到相邻日期的患者数、成功复制的文件夹数等）。

核心逻辑
对 Excel 中每位患者（去重后），取第一次出现的日期作为“基准日期”。
遍历源目录，构建每位患者的所有就诊日期列表（YYYY-MM-DD 格式）。
在排序后的日期列表中，利用二分查找找到基准日期的插入位置，取前一个（若存在）和后一个（若存在）日期作为相邻就诊。
将这两个相邻日期对应的整个文件夹复制到目标目录（若目标已存在则跳过）。
无需基准日期必须存在于就诊列表中（即使录入日期略有偏差，也能取到实际的前后邻近记录）。
